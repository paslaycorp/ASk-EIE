## What This Is

The **Alexandrian State Kernel (AKS)** is a formal foundational standard for AI systems — not "another AI framework," but a **formal identity** with an immutable core and extensible subsystems.

The **Epistemic Integrity Engine (EIE)** is the first production subsystem built atop AKS. It is a quantum-inspired LLM integrity layer that knows **when not to answer confidently**.

## Core Philosophy

- **Honesty over Fluency** — A hesitant truth is better than a confident lie
- **Provenance over Authority** — *Why* you know matters more than *that* you know
- **Contradiction as Feature** — Disagreement is data, not error
- **Decay as Truth** — Confidence without refresh is arrogance
- **Collapse as Courage** — Refusing to answer is sometimes the only honest answer
